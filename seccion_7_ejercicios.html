SQL Quest: El Ascenso

Tu viaje desde el GROUP BY hasta la Maestría Analítica

Dataset: Tabla 'trips' (Taxis) | Motor: SQL Server

Nivel 1: El Despertar de la Ventana

⚡ Poder Desbloqueado: OVER()

El problema: Hasta ahora, el GROUP BY colapsaba tus filas. Perdías el detalle.

La solución: OVER() abre una "ventana" sobre los datos. Te permite calcular agregados (SUM, AVG) sin destruir la fila original.

Reto 01: La Visión Global

Calcula el promedio de duración de TODOS los viajes y muéstralo junto a cada viaje individual.

SELECT TOP 10
    id, 
    trip_duration,
    AVG(trip_duration) OVER() AS promedio_global
FROM trips;
Reto 02: La Comparación Inmediata

¿Es este viaje más largo o más corto que el promedio global?

SELECT TOP 10
    id, 
    trip_duration,
    trip_duration - AVG(trip_duration) OVER() AS diferencia_vs_global
FROM trips;
Reto 03: El Peso del Individuo

¿Qué porcentaje representa la duración de este viaje sobre el tiempo TOTAL de todos los viajes?

SELECT TOP 10
    id, 
    trip_duration,
    CAST(trip_duration AS FLOAT) / SUM(trip_duration) OVER() * 100 AS pct_del_total
FROM trips;
Reto 04: Contando sin Agrupar

Muestra el ID del viaje y cuántos viajes existen en total en la tabla (en cada fila).

SELECT TOP 10
    id, 
    COUNT(*) OVER() AS total_filas_tabla
FROM trips;
Reto 05: El Máximo Histórico

Muestra junto a cada viaje, cuál es el viaje más largo registrado en toda la base.

SELECT TOP 10
    id, 
    trip_duration,
    MAX(trip_duration) OVER() AS record_global
FROM trips;

Nivel 2: La Habilidad de Particionar

⚡ Poder Desbloqueado: PARTITION BY

El concepto: OVER() ve todo. PARTITION BY crea mini-ventanas. Es como hacer un GROUP BY para el cálculo, pero manteniendo las filas.

Reto 06: Contexto del Proveedor

Calcula el promedio de duración, pero SOLO considerando los viajes de ese mismo `vendor_id`.

SELECT TOP 10
    id, 
    vendor_id,
    trip_duration,
    AVG(trip_duration) OVER(PARTITION BY vendor_id) AS promedio_vendor
FROM trips;
Reto 07: Volumen por Proveedor

Cuenta cuántos viajes hizo el proveedor de la fila actual.

SELECT TOP 10
    id, 
    vendor_id,
    COUNT(*) OVER(PARTITION BY vendor_id) AS total_viajes_vendor
FROM trips;
Reto 08: Porcentaje de Carga del Proveedor

De todo el tiempo trabajado por el Vendor 1, ¿cuánto representa este viaje específico?

SELECT TOP 10
    id, 
    vendor_id,
    trip_duration,
    CAST(trip_duration AS FLOAT) / SUM(trip_duration) OVER(PARTITION BY vendor_id) * 100 AS pct_contribucion_vendor
FROM trips;
Reto 09: Análisis por Pasajeros

Calcula la duración máxima observada para viajes con la misma cantidad de pasajeros.

SELECT TOP 10
    id, 
    passenger_count,
    trip_duration,
    MAX(trip_duration) OVER(PARTITION BY passenger_count) AS max_duracion_grupo
FROM trips;
Reto 10: Partición Múltiple

Particiona por Proveedor Y por Día. El cálculo se reinicia cada día para cada proveedor.

SELECT TOP 10
    id, 
    vendor_id,
    CAST(pickup_datetime AS DATE) AS dia,
    COUNT(*) OVER(PARTITION BY vendor_id, CAST(pickup_datetime AS DATE)) AS viajes_ese_dia_ese_vendor
FROM trips;

Nivel 3: El Orden y el Marco

⚡ Poder Desbloqueado: ORDER BY (dentro de OVER)

El concepto: Cuando añades ORDER BY dentro de la ventana, cambias el comportamiento. Ahora la función se aplica "fila a fila" acumulando valores. Creas Running Totals.

Reto 11: Total Acumulado (Running Total)

Suma la duración de los viajes acumulada cronológicamente a lo largo de los días.

SELECT TOP 20
    id, 
    pickup_datetime,
    trip_duration,
    SUM(trip_duration) OVER(ORDER BY pickup_datetime) AS duracion_acumulada_historica
FROM trips;
Reto 12: Acumulado Reiniciable

Suma acumulada, pero se reinicia a 0 cuando cambia el proveedor (Partition + Order).

SELECT TOP 20
    id, 
    vendor_id,
    pickup_datetime,
    trip_duration,
    SUM(trip_duration) OVER(PARTITION BY vendor_id ORDER BY pickup_datetime) AS acumulado_vendor
FROM trips;
Reto 13: El Récord Móvil

Muestra cuál era la duración máxima vista *hasta ese momento* en el tiempo.

SELECT TOP 20
    pickup_datetime,
    trip_duration,
    MAX(trip_duration) OVER(ORDER BY pickup_datetime) AS maximo_hasta_ahora
FROM trips;
Reto 14: Promedio Móvil Simple

Promedio de duración de todos los viajes hasta el punto actual.

SELECT TOP 20
    id, 
    trip_duration,
    AVG(trip_duration) OVER(ORDER BY pickup_datetime) AS promedio_movil_historico
FROM trips;

Nivel 4: Jerarquías y Rankings

⚡ Poder Desbloqueado: RANK(), DENSE_RANK(), ROW_NUMBER()

La misión: Asignar posiciones de podio.

  • ROW_NUMBER(): Ranking forzado (1, 2, 3, 4).
  • RANK(): Salta empates (1, 2, 2, 4).
  • DENSE_RANK(): Mantiene secuencia en empates (1, 2, 2, 3).
Reto 15: Ranking Simple

Ordena los viajes por duración descendente globalmente.

SELECT TOP 10
    id, 
    trip_duration,
    RANK() OVER(ORDER BY trip_duration DESC) AS ranking_global
FROM trips;
Reto 16: El Top 1 por Proveedor

Ranking reiniciado por proveedor. ¿Cuál es el viaje #1 de cada uno?

SELECT TOP 20
    id, 
    vendor_id,
    trip_duration,
    ROW_NUMBER() OVER(PARTITION BY vendor_id ORDER BY trip_duration DESC) AS ranking_interno
FROM trips;
Reto 17: Diferencia Rank vs Dense_Rank

Observa cómo manejan los empates.

SELECT TOP 20
    trip_duration,
    RANK() OVER(ORDER BY trip_duration DESC) AS rnk,
    DENSE_RANK() OVER(ORDER BY trip_duration DESC) AS dense_rnk
FROM trips
ORDER BY trip_duration DESC;
Reto 18: Deciles (NTILE)

Divide todos los viajes en 10 grupos de igual tamaño según su duración (del 1 al 10).

SELECT TOP 20
    id,
    trip_duration,
    NTILE(10) OVER(ORDER BY trip_duration) AS decil
FROM trips;
Reto 19: Identificar el Último Viaje

Usa Row Number ordenado por fecha DESC para marcar el viaje más reciente con un 1.

SELECT TOP 20
    id,
    vendor_id,
    pickup_datetime,
    ROW_NUMBER() OVER(PARTITION BY vendor_id ORDER BY pickup_datetime DESC) AS orden_inverso
FROM trips;
Reto 20: Detección de Duplicados

Si hay dos filas con el mismo ID, el Row Number será 2.

SELECT TOP 10
    id,
    ROW_NUMBER() OVER(PARTITION BY id ORDER BY id) AS duplicado_check
FROM trips;

Nivel 5: Viaje en el Tiempo

⚡ Poder Desbloqueado: LEAD y LAG

El concepto: Accede a la fila ANTERIOR (LAG) o a la SIGUIENTE (LEAD) sin hacer Joins complejos.

Reto 21: El Valor Anterior

Trae la duración del viaje inmediatamente anterior de este mismo proveedor.

SELECT TOP 10
    vendor_id,
    pickup_datetime,
    trip_duration,
    LAG(trip_duration) OVER(PARTITION BY vendor_id ORDER BY pickup_datetime) AS duracion_anterior
FROM trips;
Reto 22: Diferencia (Delta)

Calcula cuántos segundos más (o menos) duró este viaje respecto al anterior.

SELECT TOP 10
    vendor_id,
    trip_duration,
    trip_duration - LAG(trip_duration) OVER(PARTITION BY vendor_id ORDER BY pickup_datetime) AS delta
FROM trips;
Reto 23: Tiempo Muerto (Idle Time)

Diferencia entre el Dropoff del viaje anterior y el Pickup del viaje actual.

SELECT TOP 10
    vendor_id,
    pickup_datetime,
    LAG(dropoff_datetime) OVER(PARTITION BY vendor_id ORDER BY pickup_datetime) AS dropoff_previo,
    DATEDIFF(minute, 
        LAG(dropoff_datetime) OVER(PARTITION BY vendor_id ORDER BY pickup_datetime),
        pickup_datetime
    ) AS minutos_descanso
FROM trips;
Reto 24: Mirando al Futuro (LEAD)

¿Cuál será la duración del PRÓXIMO viaje?

SELECT TOP 10
    vendor_id,
    trip_duration,
    LEAD(trip_duration) OVER(PARTITION BY vendor_id ORDER BY pickup_datetime) AS siguiente_duracion
FROM trips;
Reto 25: First Value del Día

Compara cada viaje del día con el PRIMER viaje de ese mismo día.

SELECT TOP 10
    pickup_datetime,
    trip_duration,
    FIRST_VALUE(trip_duration) OVER(PARTITION BY CAST(pickup_datetime AS DATE) ORDER BY pickup_datetime) AS primera_duracion_dia
FROM trips;

Nivel 6: El Arquitecto (CTEs)

⚡ Poder Desbloqueado: WITH (Common Table Expressions)

El problema: Las subconsultas anidadas son difíciles de leer.

La solución: Crea "tablas temporales virtuales" para organizar tu lógica paso a paso.

Reto 26: CTE de Limpieza

Paso 1: Limpia los datos. Paso 2: Selecciónalos.

WITH DatosLimpios AS (
    SELECT id, vendor_id, trip_duration 
    FROM trips 
    WHERE trip_duration IS NOT NULL AND trip_duration > 0
)
SELECT TOP 10 * FROM DatosLimpios;
Reto 27: CTE de Agregación

Calcula totales diarios en una CTE y úsalos después.

WITH ResumenDiario AS (
    SELECT CAST(pickup_datetime AS DATE) AS Fecha, SUM(trip_duration) AS Total
    FROM trips
    GROUP BY CAST(pickup_datetime AS DATE)
)
SELECT * FROM ResumenDiario ORDER BY Fecha;
Reto 28: CTE + Window Function

Usa el resultado de la CTE para hacer un ranking de los días con más tráfico.

WITH ResumenDiario AS (
    SELECT CAST(pickup_datetime AS DATE) AS Fecha, COUNT(*) AS CantidadViajes
    FROM trips
    GROUP BY CAST(pickup_datetime AS DATE)
)
SELECT 
    Fecha, 
    CantidadViajes, 
    RANK() OVER(ORDER BY CantidadViajes DESC) AS RankingDia
FROM ResumenDiario;
Reto 29: Filtrando el Resultado de Window Function

¡Truco! No puedes usar WHERE sobre un ranking directamente. Necesitas una CTE.

WITH RankingCalculado AS (
    SELECT id, vendor_id, ROW_NUMBER() OVER(PARTITION BY vendor_id ORDER BY trip_duration DESC) AS rn
    FROM trips
)
SELECT * FROM RankingCalculado WHERE rn = 1;
Reto 30: CTEs Encadenadas

Define una CTE y úsala dentro de la siguiente CTE.

WITH Paso1 AS (
    SELECT id, trip_duration FROM trips WHERE trip_duration > 100
),
Paso2 AS (
    SELECT id, trip_duration * 2 AS duracion_doble FROM Paso1
)
SELECT TOP 5 * FROM Paso2;

Misión: Todo o Nada

El CFO exige un reporte mensual con:

  1. Limpieza de datos (CTE).
  2. Agregación mensual (CTE).
  3. Crecimiento vs Mes Anterior (Window Function - LAG).
  4. Acumulado del año (Window Function - SUM).

EL GOLPE FINAL (Reto 40: Query Maestra)

Ejecuta esto en tu consola para ganar el juego.

WITH DataLimpia AS (
    SELECT vendor_id, CAST(pickup_datetime AS DATE) AS Fecha, trip_duration
    FROM trips WHERE trip_duration > 0
),
AgregadoMensual AS (
    SELECT vendor_id, YEAR(Fecha) AS Anio, MONTH(Fecha) AS Mes, SUM(trip_duration) AS Total
    FROM DataLimpia
    GROUP BY vendor_id, YEAR(Fecha), MONTH(Fecha)
)
SELECT 
    vendor_id, Anio, Mes, Total,
    -- Ataque 1: Crecimiento MoM
    LAG(Total) OVER(PARTITION BY vendor_id ORDER BY Anio, Mes) AS Mes_Anterior,
    (Total - LAG(Total) OVER(PARTITION BY vendor_id ORDER BY Anio, Mes)) AS Diferencia_Neta,
    
    -- Ataque 2: Acumulado YTD
    SUM(Total) OVER(PARTITION BY vendor_id, Anio ORDER BY Mes) AS Acumulado_Anual
FROM AgregadoMensual
ORDER BY vendor_id, Anio, Mes;
