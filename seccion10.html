Delta Live Tables (DLT)

Olvida escribir tareas, dependencias y checkpoints manualmente.
DLT cambia el paradigma de Imperativo ("haz esto, luego esto") a Declarativo ("quiero esta tabla, calculada así").

01. ¿Por qué usarlo?

La ingeniería de datos tradicional es frágil. Si falla el paso 3 de 10, ¿cómo reinicias? ¿Cómo garantizas la calidad? DLT automatiza la fontanería:

  • DAG Automático

    Spark infiere las dependencias. Si la tabla B lee de la A, DLT ejecuta A primero. Sin Airflow.

  • Expectations (Calidad)

    Define reglas como CONSTRAINT valid_id EXPECT (id IS NOT NULL). DLT monitorea y alerta si se rompen.


@dlt.table(
    comment="Datos limpios de ventas"
)
@dlt.expect_or_drop("valid_monto", "monto > 0")
def ventas_silver():
    return (
        dlt.read("ventas_bronze")
        .filter(...)
    )
Código Declarativo: Defines el "Qué", no el "Cómo".

02. Garantía ACID en el Lakehouse

A

Atomicidad

O todo se escribe o nada se escribe. Si el pipeline falla al 99%, no quedan archivos corruptos o parciales visibles.

C

Consistencia

Cada lectura ve una instantánea válida de los datos. DLT gestiona el _delta_log para asegurar serializabilidad.

I

Aislamiento

Un usuario leyendo la tabla NO se bloquea mientras DLT está escribiendo nuevos datos. Lecturas y escrituras son concurrentes.

D

Durabilidad

Una vez que DLT confirma el commit en el log, los datos están seguros en el almacenamiento (S3/ADLS/HDD), sobreviviendo a fallos del sistema.

03. Consideraciones Críticas

Antes de desplegar a producción, ten en cuenta estos factores de arquitectura.

Streaming vs Batch

DLT abstrae esto, pero debes decidir. Usar spark.readStream permite latencia casi real, pero requiere que el origen soporte streaming. DLT maneja el estado automáticamente.

Evolución de Esquemas

¿Qué pasa si llega una columna nueva? DLT puede evolucionar el esquema automáticamente si configuras las propiedades correctas, o fallar para proteger el downstream.

Costo Computacional (DBU)

DLT "Continuous" mantiene el cluster encendido 24/7. Para cargas batch diarias, usa el modo "Triggered" para ahorrar costos masivos.
